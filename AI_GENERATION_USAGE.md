# 🤖 Использование ИИ-генерации постов

## ✅ Что реализовано

### 1. **Сервис генерации** (`app/services/ai_generation.py`)
- `AIGenerationService` — полнофункциональный сервис генерации через OpenRouter API
- Поддержка переменных в промптах
- Автоматическая генерация хештегов и CTA
- Модерация контента
- Учёт лимитов токенов

### 2. **Интеграция с редактором постов**
- Кнопка "🤖 ИИ" в редакторе с предпросмотром
- Меню выбора действий:
  - 📝 Генерация текста по теме
  - 🔗 Генерация из ссылки (в разработке)
  - ✨ Улучшение текста (в разработке)

### 3. **Настройки в меню канала**
- **ИИ → Текст**: пресеты, тон, длина, эмодзи
- **ИИ → Хештеги/CTA**: управление генерацией
- **ИИ → Модерация**: фильтрация контента

## 🚀 Как использовать

### Шаг 1: Настройка API ключа

Добавьте в `.env`:
```bash
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxx
OPENROUTER_MODEL=openai/gpt-4o-mini  # или другая модель
```

### Шаг 2: Настройка канала

1. Перейдите в **Настройки** → **Список каналов** → Выберите канал
2. Нажмите **🤖 ИИ**
3. Настройте параметры:
   - **Текст**: выберите пресет или настройте свой промпт
   - **Хештеги/CTA**: включите генерацию, выберите количество
   - **Модерация**: добавьте запрещённые слова (опционально)

### Шаг 3: Создание поста с ИИ

1. Создайте новый пост (Главное меню → Создать пост)
2. Выберите канал
3. В редакторе нажмите **🤖 ИИ**
4. Выберите **📝 Генерация текста**
5. Введите тему поста, например:
   - "Акция на зимнюю коллекцию обуви со скидкой 50%"
   - "Обзор новых функций iOS 18"
   - "Розыгрыш призов среди подписчиков"
6. Дождитесь генерации
7. Отредактируйте текст (если нужно)
8. Опубликуйте!

## 📊 Доступные пресеты

1. **🎁 Акция (коротко)** — продающие посты для акций
2. **📰 Новость (средний)** — информационные посты
3. **📚 Обучающий (подробный)** — образовательный контент
4. **🎭 Развлекательный** — лёгкие посты с юмором
5. **📢 Официальное объявление** — формальный стиль
6. **⭐ Обзор продукта/услуги** — детальные обзоры
7. **✏️ Свой промпт** — кастомная настройка

## ⚙️ Настройка параметров

### Тон
- **Дружелюбный** — неформальный, лёгкий
- **Экспертный** — профессиональный, информативный
- **Официальный** — формальный, деловой
- **Провокационный** — эмоциональный, вызывающий

### Длина
- **Короткий** — до 500 символов
- **Средний** — 500-1200 символов
- **Длинный** — 1200+ символов

### Эмодзи
- **0** — без эмодзи
- **1** — умеренно (рекомендуется)
- **2** — много
- **3** — очень много

### Хештеги
- Количество: 1, 2, 3, 5 или 7
- Генерируются автоматически на основе темы
- Добавляются в конец поста

### CTA (Call-To-Action)
- Автоматический призыв к действию
- Генерируется на основе контекста
- Добавляется в конец поста

## 🔒 Модерация

Настройте в **ИИ → Модерация**:

1. **Модерация** — вкл/выкл фильтрации
2. **Запрещённые слова** — список нежелательных слов (в разработке)
3. **Ссылки** — разрешить/запретить в сгенерированном тексте
4. **UTM-метки** — автодобавление utm_source и utm_medium

## 💡 Советы по использованию

### Хорошие темы для генерации:
✅ "Акция на зимнюю коллекцию обуви со скидкой 50%"
✅ "Новое обновление приложения с функцией темной темы"
✅ "Розыгрыш 3 iPhone 15 Pro среди подписчиков"
✅ "Как улучшить продуктивность: 5 проверенных способов"

### Плохие темы:
❌ "пост" (слишком общее)
❌ "напиши что-нибудь" (нет конкретики)
❌ "" (пустая тема)

### Переменные в промптах

При настройке своего промпта можно использовать:
- `{topic}` — тема поста
- `{tone}` — тон (friendly, expert, official, provocative)
- `{length}` — длина (short, medium, long)
- `{emoji_level}` — уровень эмодзи (0-3)
- `{lang}` — язык (ru)
- `{brand}` — название бренда
- `{audience}` — целевая аудитория
- `{cta}` — призыв к действию
- `{hashtags}` — количество хештегов
- `{channel_title}` — название канала

## 📈 Учёт токенов

- Каждая генерация учитывает использованные токены
- Счётчики обновляются автоматически
- Можно установить дневные/месячные лимиты (в настройках БД)

## 🐛 Возможные ошибки

### "OPENROUTER_API_KEY не настроен"
→ Добавьте ключ в `.env` и перезапустите бота

### "ИИ не включён для этого канала"
→ Зайдите в настройки канала → ИИ → включите

### "Контент не прошёл модерацию"
→ Проверьте запрещённые слова или отключите модерацию

### HTTP 401 Unauthorized
→ Проверьте правильность API ключа

### HTTP 429 Too Many Requests
→ Превышен лимит запросов, подождите

## 📚 API Reference

### Сервис генерации

```python
from app.services.ai_generation import AIGenerationService

async with AsyncSessionLocal() as session:
    service = AIGenerationService(session)
    
    # Генерация текста
    result = await service.generate_post_text(
        channel_id=123,
        topic="Тема поста",
        context={"brand": "MyBrand", "cta": "Подпишитесь"}
    )
    
    # Улучшение текста
    result = await service.improve_text(
        channel_id=123,
        original_text="Исходный текст",
        instruction="сделать более продающим"
    )
    
    # Генерация только хештегов
    hashtags = await service.generate_hashtags_only(
        channel_id=123,
        text="Текст поста"
    )
    
    # Генерация только CTA
    cta = await service.generate_cta_only(
        channel_id=123,
        text="Текст поста"
    )
```
