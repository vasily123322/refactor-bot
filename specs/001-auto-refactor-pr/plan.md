# Implementation Plan: Auto-Refactor Pull Requests

## Scope & Goals
- Мелкие безопасные улучшения (стиль, типизация, dead code, micro‑perf) без изменения поведения.
- Минимальные диффы, соблюдение локальных соглашений и «зелёный» CI.

## Architecture Overview
- Оркестратор (бот/скрипт) формирует небольшие батчи изменений и открывает PR.
- Правила/пороги и исключения — из `.specify/refactor-bot.yaml`.
- Предварительные проверки: линтеры/тесты (см. `ci.preCheck`).

## Phases
1) Bootstrap
   - Подготовить конфиг `.specify/refactor-bot.yaml` (пороги, exclude, категории, preCheck).
   - Не менять существующие форматтеры/линтеры; следовать им.

2) Static Analysis (candidate finding)
   - Собрать кандидатов: неиспользуемые импорты/переменные, мёртвые функции, простые типизационные подсказки, микровыигрыши (не меняя поведение).
   - Исключить двоичные/сгенерированные/миграции/снапшоты (из `exclude`).

3) Small Batch Changes (apply)
   - Ограничения: `maxChangedLines`, `maxFiles`; трогать только нужные строки, сохранять комментарии.
   - Не добавлять зависимости, не менять форматтер/линтер‑конфиг без согласования.

4) Pre‑Check & PR
   - Запуск `ci.preCheck` (линтеры/тесты). На провал — дробить батч или откатить.
   - Заголовок PR: `chore(refactor-bot): <summary>`; тело: категории, отсутствие изменения поведения, логи проверок.

5) Iterate
   - Повторять малыми батчами; избегать конфликтов частым запуском.

6) Observability
   - Метрики: merge rate ≥ 80%, TTR < 24h, снижение линтер‑warning’ов на затронутых модулях.

## Safety Rules
- Не трогать поведение; не менять публичные API/контракты.
- Сохранять лицензии/заголовки/комментарии; не трогать бинарники, миграции, снапшоты.

## Files
- Create: `.specify/refactor-bot.yaml` (по умолчанию безопасные пороги и exclude).
- Update (опционально): `.gitignore` — убедиться, что `.cursor/` и чувствительное исключено.

## Dependencies
- Используем существующие линтеры/тесты. Новые зависимости не добавляем без явного запроса.

## Rollback Strategy
- Закрыть PR/откатить коммит. Изменений в main не остаётся.
