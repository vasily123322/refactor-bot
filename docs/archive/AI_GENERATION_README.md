# 🤖 ИИ-Генерация постов - Инструкция

## ✅ Что реализовано

### 1. Сервис генерации текста
- **`AIGenerationService`** — сервис для работы с OpenRouter API
- Поддержка пресетов и кастомных промптов
- Подстановка переменных (тема, тон, длина, эмодзи, язык и т.д.)
- Обработка ошибок и таймаутов
- Счётчик использованных токенов

### 2. Интеграция с редактором постов
- Кнопка **"🤖 ИИ"** в редакторе с предпросмотром
- Меню с опциями:
  - **Генерация текста** — создание поста по теме
  - **Генерация из ссылки** — саммари/рерайт (в разработке)
  - **Генерация медиа** — изображения (в разработке)

### 3. FSM-состояния
- `AIFSM.topic_input` — ввод темы для генерации
- `AIFSM.link_input` — ввод ссылки (в разработке)
- `AIFSM.improvement_choice` — выбор типа улучшения (в разработке)

## 🚀 Как использовать

### Шаг 1: Настройте OpenRouter API Key

Добавьте в `.env` файл:
```env
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxx
OPENROUTER_MODEL=openai/gpt-4o-mini
OPENROUTER_TEMPERATURE=0.7
OPENROUTER_TOP_P=0.9
```

### Шаг 2: Установите зависимости

```bash
cd /home/refactor_bot
source venv/bin/activate
pip install httpx>=0.27.0
```

### Шаг 3: Настройте ИИ для канала

1. Откройте **Настройки** → **Список каналов** → Выберите канал
2. Нажмите **🤖 ИИ**
3. Перейдите в **Текст**
4. Выберите пресет или настройте свой промпт
5. Настройте параметры:
   - **Тон**: дружелюбный / экспертный / официальный / провокационный
   - **Длина**: короткий / средний / длинный
   - **Эмодзи**: 0-3 (без / умеренно / много / очень много)
   - **Язык**: RU
6. Перейдите в **Хештеги/CTA**
7. Включите хештеги и выберите количество (1-7)
8. Включите CTA (призыв к действию)

### Шаг 4: Генерируйте посты

#### Способ 1: Из редактора постов
1. Создайте новый пост: **Создать пост** → Выберите канал
2. В редакторе нажмите **🤖 ИИ**
3. Выберите **"Генерация текста"**
4. Введите тему, например:
   - "Новая коллекция одежды весна 2025"
   - "5 способов повысить продуктивность"
   - "Скидка 20% на все товары до конца недели"
5. Бот сгенерирует текст и покажет предпросмотр
6. Отредактируйте при необходимости
7. Нажмите **"Далее"** → **"Опубликовать"**

#### Способ 2: С медиа
1. Отправьте фото/видео
2. Нажмите **🤖 ИИ** → **"Генерация текста"**
3. Введите тему
4. ИИ сгенерирует caption (подпись) к медиа

## 📊 Пресеты промптов

### 1. 🎁 Акция (коротко)
- Тип: Продающий
- Длина: 2-3 абзаца (до 500 символов)
- Тон: Дружелюбный
- Эмодзи: Умеренно (1)

### 2. 📰 Новость (средний)
- Тип: Информационный
- Длина: 3-5 абзацев (500-1200 символов)
- Тон: Экспертный
- Структура: Заголовок + краткое изложение + детали + выводы

### 3. 📚 Обучающий (подробный)
- Тип: Образовательный
- Длина: 5-8 абзацев (1200+ символов)
- Тон: Экспертный
- Включает: Примеры, список ключевых пунктов

### 4. 🎭 Развлекательный
- Тип: Лёгкий контент
- Длина: Средняя
- Тон: Дружелюбный
- Эмодзи: Много (2-3)

### 5. 📢 Официальное объявление
- Тип: Формальный
- Длина: Средняя
- Тон: Официальный
- Эмодзи: Минимум или без них

### 6. ⭐ Обзор продукта/услуги
- Тип: Аналитический
- Длина: Средняя/длинная
- Структура: Описание + плюсы + минусы + итог

### 7. ✏️ Свой промпт
- Настраивается вручную в настройках канала

## 🔧 Переменные в промптах

При создании своего промпта можно использовать переменные:

- `{topic}` — тема поста (введённая пользователем)
- `{tone}` — тон (дружелюбный/экспертный/официальный/провокационный)
- `{length}` — длина (короткий/средний/длинный)
- `{emoji_level}` — уровень эмодзи (0-3)
- `{lang}` — язык (RU)
- `{channel_title}` — название канала
- `{brand}` — бренд (= название канала)
- `{audience}` — аудитория (по умолчанию "подписчики канала")
- `{cta}` — призыв к действию
- `{hashtags}` — инструкция по хештегам

Пример своего промпта:
```
Ты — копирайтер канала "{channel_title}".
Создай пост на тему: {topic}
Тон: {tone}
Длина: {length}
Эмодзи: {emoji_level}
{hashtags}
{cta}
```

## 💰 Токены и лимиты

- Каждая генерация использует токены OpenRouter
- Счётчик токенов автоматически обновляется
- В настройках можно установить дневные/месячные лимиты (пока в разработке)
- После генерации показывается количество использованных токенов

## ❌ Обработка ошибок

### Типичные ошибки:

1. **"OPENROUTER_API_KEY не установлен"**
   - Решение: Добавьте ключ в `.env` файл

2. **"HTTP ошибка 401"**
   - Решение: Проверьте правильность API ключа

3. **"HTTP ошибка 429"**
   - Решение: Превышен лимит запросов, подождите

4. **"Таймаут запроса"**
   - Решение: Попробуйте ещё раз или увеличьте `timeout`

5. **"Канал не выбран"**
   - Решение: Создайте пост, выбрав канал
